# 04: I2C (TWSI) Controller

**Status: not started.**

## Scope

Register interface, bus-speed configuration, transfer state machine, FIFO and interrupt behavior, and bus-recovery requirements.

| Instances | DT compatible | Bases |
|---|---|---|
| i2c0, 1, 2, 4, 5, 6, 8 | `spacemit,k3-i2c` (fallback `spacemit,k1-i2c`) | `0xD4010800`, `0xD4011000`, `0xD4012000`, `0xD4012800`, `0xD4013800`, `0xD4018800`, `0xD401D800` |

The CoM260 uses i2c2 (ID EEPROM), i2c6 (temperature sensor) and i2c8 (PMIC).

Clock and reset IDs for these blocks are in [01](01-clocks-resets.md).
